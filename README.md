# BTC Market Intelligence Terminal — Институциональный квантово-аналитический комплекс

**BTC Market Intelligence Terminal** — это профессиональная квантовая аналитическая система для глубокого анализа рынка Bitcoin (BTC), оценки рыночного позиционирования, расчета динамических уровней риска и автоматизированной генерации отчетов.

Система входит в состав персональной экосистемы **Second Brain** руководителя и напрямую интегрируется с процессами управления капиталом в **LifeOS** (`Trading Journal`).

Проект разработан со строгим соблюдением институциональных стандартов разработки и делового стиля (Zero Emojis).

---

## Ключевые возможности

1. **Количественный скоринг позиционирования (Quant Bias Score):**
   - Сведение ключевых рыночных параметров (1D VWAP, 24H Spot CVD, дисбаланс книги ордеров спота и деривативов, дивергенции) в единую объективную шкалу от -100 (Extreme Bearish) до +100 (Extreme Bullish).
2. **Динамическая модель риска (Dynamic ATR Risk Model):**
   - Расчет адаптивных торговых параметров на основе текущей волатильности ATR14.
   - Защитный буфер Stop-Loss: `1.5 * ATR14`.
   - Целевые уровни прибыли с фиксированным математическим ожиданием: `TP1 = 1:2 R:R`, `TP2 = 1:3 R:R` для Long и Short сценариев.
3. **Ончейн-аналитика макроцикла:**
   - Экспресс-опрос BGeometrics REST API для мгновенной классификации фазы рынка по метрикам MVRV Z-Score и NUPL.
4. **Сверхбыстрый консольный сканер (Fast Momentum Scanner):**
   - Параллельный опрос REST API Binance и Bybit за 1.0–1.5 секунды через флаг `--fast` без вызова тяжелых браузерных скраперов.
5. **Интерактивный веб-дашборд (Streamlit / Plotly):**
   - Полукруглый спидометр Quant Bias, графики свечей BTC с наложенными линиями ATR-риска, кумулятивная дельта объемов CVD, встроенный просмотрщик PDF-отчетов и калибровка винрейта.
6. **Автономный фоновый демон (Daemon Engine):**
   - Круглосуточный фоновый мониторинг рынка с атомарным обновлением `market_snapshot.json` и контролем процесса через PID-файлы.
7. **Встроенный офлайн-тест самодиагностики:**
   - 13 автономных сьютов проверки математики, риск-моделей и парсеров (`--self-test`) с гарантированным прохождением без сетевого доступа.

## Быстрый старт и запуск

### Требования к окружению
- Python 3.14 (или >= 3.11).
- Менеджер пакетов `uv` (рекомендуется) или стандартный `pip`.

### Развертывание окружения
```bash
# Переход в директорию проекта
cd C:\btc-market-intelligence

# Создание виртуального окружения и установка зависимостей через uv
uv venv
uv pip install -r requirements.txt
```

### Конфигурация (.env)
Скопируйте шаблон переменных окружения:
```bash
copy .env.example .env
```
Основные параметры:
- `GEMINI_API_KEY`: Ключ Google AI Studio для ИИ-синтеза ежедневного отчета (опционально, для Fast Mode не требуется).
- `LOCAL_TIMEZONE`: Часовой пояс (`Europe/Riga`).
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`: Настройки доставки алертов в Telegram.

## Режимы запуска

### 1. Мгновенное сканирование рынка (Fast Mode, ~1.0 сек)
```bash
uv run python btc_market_intelligence.py --fast
```
*Выводит в консоль сводный Quant Bias скоринг, текущие цены деривативов, открытый интерес, фазу ончейна и точные уровни Stop-Loss и Take-Profit (1:2, 1:3).*

### 2. Запуск автономного теста самодиагностики (Self-Test)
```bash
uv run python btc_market_intelligence.py --self-test
```
*Запускает 13 автономных офлайн-тестов математики и алгоритмов. Завершается с кодом 0.*

### 3. Интерактивный веб-дашборд
```bash
uv run streamlit run dashboard.py
# либо запуск через пакетный файл Windows:
run_dashboard.bat
```
*Открывает дашборд в браузере по адресу `http://localhost:8501`.*

### 4. Автономный фоновый демон мониторинга
```bash
uv run python daemon_engine.py --interval 60
```
*Запускает непрерывный мониторинг с интервалом обновления 60 секунд и записью в `market_snapshot.json`.*

### 5. Полный цикл анализа с генерацией PDF-отчета
```bash
uv run python btc_market_intelligence.py
```
*Выполняет полный сбор данных, Playwright-скрапинг тепловых карт, генерацию `daily_report.md` и сборку `daily_report.pdf`.*

## Интеграция с экосистемой LifeOS Second Brain

Терминал `btc-market-intelligence` служит поставщиком аналитики для операционной системы руководителя `LifeOS`:
1. **Торговый журнал (`Trading Journal`):** Координаты входа, Stop-Loss и Take-Profit, рассчитанные модулем `calculate_atr_risk_levels`, служат основой для фиксации сделок в Google Sheets.
2. **Утренний брифинг (09:00):** Значение `Quant Bias` и фаза MVRV/NUPL интегрируются в ежедневный утренний статус руководителя в Telegram.
3. **Единый технологический стек:** Общий часовой пояс (`Europe/Riga`), стандарты отказоустойчивости и стиль оформления Zero Emojis.
