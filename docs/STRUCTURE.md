## 2. Детальная ответственность модулей

### `btc_market_intelligence.py`
- Главная точка входа аналитического ядра (~181 КБ).
- Ключевые функции:
  - `run_fast_momentum_scan(quiet=False)`: параллельный опрос REST API Binance, Bybit и BGeometrics за 1-2 секунды, расчет Quant Bias и уровней риска.
  - `calculate_quant_bias(...)`: вычисление сводного скоринга от -100 до +100 на основе 5 взвешенных факторов.
  - `calculate_atr_risk_levels(...)`: расчет динамической риск-модели на основе ATR14, буфера 1.5x и целей с R:R 1:2 и 1:3.
  - `fetch_onchain_metrics(...)`: быстрый опрос BGeometrics REST API для получения MVRV Z-Score и NUPL.
  - `run_self_tests()`: выполнение 13 наборов офлайн-тестов при флаге `--self-test`.
  - `generate_pdf_report(...)`: компиляция итогового PDF-документа с графиками и таблицами через `reportlab`.

### `dashboard.py`
- Полнофункциональный интерактивный веб-дашборд на `streamlit` (~84 КБ).
- Ключевые возможности:
  - Отрисовка полукруглого спидометра Quant Bias с динамической цветовой индикацией.
  - Построение интерактивных графиков Plotly: свечи BTC с наложенными линиями Stop-Loss и Take-Profit, кумулятивная дельта CVD, Z-score открытого интереса.
  - Панель быстрого запуска сканирования через безопасный `subprocess.Popen` с потоковым выводом логов.
  - Встроенный просмотрщик сформированного PDF-отчета через Base64 `iframe`.
  - Интерактивная таблица винрейта и калибровки торговых сигналов.

### `daemon_engine.py`
- Автономный демон для круглосуточного фонового мониторинга рынка.
- Обеспечивает:
  - Регулярный запуск быстрого сканирования рынка с заданным интервалом (по умолчанию 60 секунд).
  - Атомарное сохранение `market_snapshot.json` через временный файл `.tmp` для исключения гонок при чтении.
  - Запись PID-файла (`daemon.pid`) и корректную обработку сигналов `SIGINT` и `SIGTERM`.
  - Ведение статуса в `daemon_status.json`.

### `telegram_notifier.py`
- Диспетчер доставки оповещений и документов в Telegram.
- Методы:
  - `send_telegram_message(text, parse_mode='HTML')`: отправка текстовых уведомлений.
  - `send_telegram_document(document_path, caption)`: отправка скомпилированного PDF-отчета.
  - `send_market_alert(snapshot)`: отправка алерта при фиксации экстремальных значений Quant Bias.

### `quant_enhancements.py`
- Библиотека дополнительных количественных расчетов:
  - Анализ аномалий в книге ордеров (Bid/Ask Imbalance).
  - Расчет Z-score ставки финансирования и открытого интереса.
  - Детекция дивергенций между динамикой спотовой цены и кумулятивной дельтой объемов (CVD Divergence).

### `ui_components.py`
- Набор переиспользуемых визуальных блоков Streamlit:
  - Карточки ключевых показателей (KPI Cards) в строгом стиле.
  - Стилизованные контейнеры для таблиц калибровки.
  - Бейджи статусов торговых рекомендаций (`LONG`, `SHORT`, `NEUTRAL`).

## 3. Режимы запуска и интерфейсы вызова (CLI Interfaces)

| Команда | Описание | Типичное время выполнения |
|---|---|---|
| `uv run python btc_market_intelligence.py --fast` | Мгновенный консольный срез рынка, Quant Bias и ATR-риск | **1.0 — 1.5 сек** |
| `uv run python btc_market_intelligence.py --self-test` | Полный автономный офлайн-тест всех математических модулей | **0.8 сек** |
| `uv run python btc_market_intelligence.py` | Полный цикл: скрапинг Playwright + AI Gemini + PDF | **15 — 35 сек** |
| `uv run streamlit run dashboard.py` | Запуск локального интерактивного веб-интерфейса | Постоянно (порт 8501) |
| `uv run python daemon_engine.py --interval 60` | Запуск автономного фонового демона мониторинга | Постоянно (фоновый процесс) |

## 4. Инженерные стандарты и конвенции

1. **Строгое отсутствие эмодзи (Zero Emojis):**
   - Все консольные выводы, логи, отчеты Markdown/PDF и интерфейсы дашборда оформлены в строгом институциональном стиле без эмодзи.
2. **Атомарность операций ввода-вывода:**
   - Любое обновление JSON-файлов среза состояния (`market_snapshot.json`) должно производиться исключительно через временный файл с последующим атомарным замещением (`replace`).
3. **Управление зависимостями:**
   - Использование менеджера `uv` для быстрого и детерминированного развертывания виртуального окружения.
4. **Контроль секретов:**
   - Ключи `GEMINI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` хранятся строго в `.env` и никогда не фиксируются в репозитории.
